차곡 발표 시연 실행 안내

발표 중 호출 이름 (두 시연 모두 유지)
  “시연” 또는 “세로 시연”: 기존 세로 / 맑은 날 / 네온 레이서. 내비 오른쪽 보조 창과 부스터.
  “가로 빗길 시연”: 가로 2.5D / 비 오는 날 / 현대 세단. 왼쪽 깜빡이는 위쪽, 오른쪽은 아래쪽 차선.
  두 시연 모두 주유 → 재출발 → 50,000원 확인·저장 → 약 2초 후 요약. 시연 기록은 매회 새로 준비합니다.

가로 빗길 재생:
  .\tools\demo-windows.ps1 -Mode Play -Scene LandscapeRain
  Prepare / Rehearse에도 같은 -Scene 옵션을 사용합니다. 새로 준비할 때는 와이퍼 High 신호를 60초 이상 기다립니다.
  결과 캡처는 doc/demo/evidence/landscape-rain/에 따로 보관합니다.

기존 세로 시연 재생 (기본값):
  .\tools\demo-windows.ps1 -Mode Play

처음 설치·대기 화면 준비:
  .\tools\demo-windows.ps1 -Mode Prepare -Build

전체 리허설·저장 검증 후 다시 대기 화면으로:
  .\tools\demo-windows.ps1 -Mode Rehearse

진행 순서
  주행 35km/h → 왼쪽 깜빡이 → 오른쪽 깜빡이 → 85km/h까지 급가속·부스터
  → 감속·P단 → 연료 30%에서 80%로 주유 → 안정된 상승으로 후보 생성
  → 35km/h로 재출발 → “주유비, 얼마였어요?”
  → 자동 답변 “5만 원” → “50,000원, 기록할까요?” → 자동 답변 “맞아”
  → 저장 → 약 2초 후 차량 요약에서 주유 50,000원 확인

시연 구분
  실제 차량 SDK: 속도·기어·깜빡이·누적 거리.
  시연 재생: 연료 잔량 30%→80%, STT 결과 “5만 원”·“맞아”.
  실제 앱 기능: 잔량 안정 감지, 후보·초안·확정, SQLite 저장, 월 합계, 요약 화면.
  주행 연출과 주행 중 질문은 .smoke 에뮬레이터 전용 예외.
  일반 앱은 기존 주행 UX 제한과 정차 후 질문을 유지.

주의할 데이터
  Prepare와 리허설 종료는 시연용 .smoke DB만 초기화합니다.
  일반 앱 io.chagok.app의 기록은 초기화하지 않습니다.
  시연 중에는 차량 신호가 일반 앱에 기록되지 않도록 일반 앱을 종료합니다.
  마지막에는 가상 차량을 속도 0·P단으로 돌립니다.
  시연값 확인은 doc/demo/evidence/verification.json과 스크린샷에 남습니다.
