차곡 v11 · 차량 요약 카드 / 가로 2.5D 주행 / 진행 방향 말풍선

적용 내용
- 차량 요약의 확인할 기록 카드와 차량 누적 거리 카드를 같은 높이로 측정한다.
  두 카드가 나란히 보이는 경우와 작은 창에서 세로로 쌓이는 경우 모두 적용한다.
  고정 높이로 글자를 자르지 않고, 내용이 더 긴 쪽의 자연 높이를 사용한다.
- 실제 주행 장면의 너비가 높이의 1.2배 이상이면 가로 장면으로 전환한다.
  시스템 헤더나 앱의 하단 버튼을 포함한 디스플레이 전체 크기를 기준으로 삼지 않는다.
- 가로에서는 오른쪽을 향한 별도 차량 그림을 사용한다. 먼 배경·도로·가까운 길의
  이동 속도를 다르게 하고, 좌회전은 위쪽 먼 차선, 우회전은 아래쪽 가까운 차선으로
  부드럽게 이동한다. 먼 차선에서는 차량을 7.5% 작게, 가까운 차선에서는 7.5% 크게 그린다.
- 세로에서는 기존 위쪽 진행 시점과 그림을 유지한다.
- 말풍선은 세로에서는 차량 앞 위쪽, 가로에서는 차량 앞 오른쪽 위에 놓인다.
  보닛 가까이 붙인 짧은 꼬리를 사용하며, 네온 스킨은 말풍선과 꼬리를 하나의 녹색 테두리로 잇는다.
- 두 스킨의 깜빡이, 속도에 따른 도로 이동, 급가속 부스터, 비, 도시/시골 전환,
  열 가지 만남과 수집을 가로 장면에도 연결했다. 창 전환 시 만남 진행률을 유지한다.

이미지 제작
Built-in image_gen으로 기존 차량/배경의 색과 화풍을 참조해 가로 전용 자산을 생성했다.
차량은 기존 위에서 본 이미지를 회전한 것이 아니라, 오른쪽을 향한 별도 시점의 그림이다.
최종 파일은 모두 app/src/main/assets/companion/ 안에 있다.
- racer-side.png: 네온 레이서, 1774×887, RGBA 투명 배경.
- hyundai-side.png: 현대 세단, 1774×887, RGBA 투명 배경.
- city-side.png: 도시 가로 도로, 1536×1024.
- country-side.png: 시골 가로 도로, 1536×1024.
- encounters-side.png: 열 가지 만남 캐릭터, 1536×1024, RGBA 투명 배경.
생성 및 알파 정리 프롬프트 원문은 image-prompts.txt와 encounter-prompt.txt에 보관했다.
Android Canvas가 도로의 세 띠를 분리해 스크롤하며, 스프라이트의 투명 여백을 잘라 그린다.
원본 세로 자산은 그대로 사용한다.

검증
- 단위 테스트 93건 통과. 화면 전환 경계, 차선 깊이, 진행 방향 말풍선 배치 포함.
- 안드로이드 스모크 17개 고유 테스트의 최종 결과 통과.
  CompanionSmokeTest 6개, ParkedDiarySmokeTest 4개, UiReviewSmokeTest 3개,
  LandscapeUiSmokeTest 4개. 변경된 말풍선은 가로/세로 두 스킨으로 추가 재검사했다.
- 카드: 320/841/1682dp, 기본 및 1.3배 글자 크기, 빈 상태와 확인할 기록이 있는 상태.
- 장면: 800×400, 1682×970, 1400×430에서 두 스킨과 좌/직진/우 이동,
  깜빡이 켜짐/꺼짐, 비, 부스터, 질문, 도시/시골, 열 가지 만남.
- 가로/세로 전환 시 동일 만남 유지, 중복 수집 방지, NO_VIDEO에서 연출 정지,
  실제 백그라운드 전환 시 프레임 정지 확인.
- 기존 픽셀 보존 검사는 먼저 검사할 크기를 설정하도록 수정했다. 활성 장면의
  창 크기 변경은 상대적 진행률을 보존하므로, 이전 검사 준비 순서와 충돌했기 때문이다.
  검증값을 완화하지 않았으며, 수정 후 원본 그림 픽셀 비교까지 통과했다.
- 실제 PLEOS 2.1.0 / Android 14 에뮬레이터의 1682×1210 창에서 42초 녹화.
  native-landscape-preview.mp4는 명시적으로 표시된 시험 앱의 정차 미리보기다.

검증 한계
기존 PLEOS NO_VIDEO 정책을 일반 앱에서 우회하지 않는다. 이번 작업은 표시 방향과
레이아웃 변경이며 SDK 주행 허용 정책 변경이나 실차 주행 검증을 의미하지 않는다.
일반 앱의 DB를 초기화하거나 시연 기록을 넣지 않았다. 스모크 앱만 시험 데이터를 사용한다.
녹화 중 에뮬레이터의 프레임 지연도 관측했다. gfxinfo 원문을 함께 보관했으며,
이번 기능·레이아웃 검증은 실차에서 30/60fps를 보장하는 성능 검증이 아니다.
