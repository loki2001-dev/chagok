# 전국 장소 목록 다운로드 — 2026-11-15 KST

공공데이터포털의 공개 표준데이터 다운로드 기능이 사용하는 JSON 응답을 전체 페이지에 걸쳐 내려받았다. API 키나 로그인 없이 공개된 다운로드 경로를 사용했다. 전국 표준데이터에 **현재 공개된 전체 레코드**이며 국내 모든 현존 업체를 빠짐없이 포괄한다는 뜻은 아니다.

| 목록 | 공개 원본 건수 | 감지용 정제 후 | 제공기관 수 | 정제 목록의 데이터 기준일 범위 |
|---|---:|---:|---:|---|
| 정비소 | 36,317 | 34,061 | 223 | 2022-07-21 ~ 2026-10-30 |
| 주유소 | 5,506 | 5,506 | 115 | 2024-08-07 ~ 2026-10-27 |
| 합계 | 41,823 | 39,567 | — | — |

- `places.json`: 차곡의 **목록 파일 가져오기**에서 사용할 버전 `2026111501` JSON. 약 9.8 MiB. 실제 앱 파서 `PlaceCatalogue.parse` 통과 확인.
- `raw/` (로컬 보관, 저장소 미포함): 헤더 메타데이터와 내려받은 원본 JSON 페이지. 정비소 4페이지, 주유소 1페이지. 페이지별 10,000건 상한과 헤더의 전체 건수 일치 확인.
- `repair.csv`, `fuel.csv` (로컬 보관, 저장소 미포함): 원본 JSON을 한국어 열 이름의 UTF-8 BOM CSV로 변환한 파일. 레코드를 생략하지 않았다.
- `repair-ready.csv`, `fuel-ready.csv` (로컬 보관, 저장소 미포함): 앱 목록 생성에 사용한 정제 입력.
- `exclusions.csv`: 제외 사유와 원본 CSV 줄 번호. 원본 파일은 수정하지 않았다.
- `audit.json`: 출처, 내려받은 시각, 건수, 제외 통계, 기준일 범위 및 SHA-256.

정비소의 영업상태 `1`과 `01`은 동일하게 처리했다. 미영업 상태 2,004건, 한국 좌표 경계(위도31~40/경도124~132) 밖 1건, 동일 장소·동일 좌표 중복 221건, 같은 이름·주소인데 좌표가 서로 다른 30건을 감지용 목록에서 제외했다. 좌표가 충돌한 경우 임의로 하나를 선택하거나 좌표를 추정하지 않았다. 주유소 원본에는 영업상태 열이 없어 현재 영업 여부까지 검증한 목록은 아니다.

다운로드 시각과 업체별 데이터 기준일은 다르다. 오래된 원본 항목이 남아 있고 지역별 제공 범위가 다를 수 있으므로 실제 방문 감지 결과는 사용자에게 확인해야 한다.

출처:
- https://www.data.go.kr/data/15028204/standard.do
- https://www.data.go.kr/data/15129441/standard.do

포털에 공개된 다운로드 스크립트 `/js/biz/mvc/std/std-download-manager.js`가 호출하는 `/download/columList.json?pk=...&ext=JSON`과 `/download/standard.json?publicDataPk=...`를 사용했다. 실제 재요청용 파라미터 `colNmList`, `svcTableNm`, `totalCount`는 저장한 헤더에서 읽었다.

로컬에 원본과 정제 CSV를 보관한 환경에서 변환 재현:

```sh
python3 tools/build_place_catalogue.py --repair data/places/repair-ready.csv --fuel data/places/fuel-ready.csv --version 2026111501 --output data/places/places.json
```

이 스냅샷은 저장소에 포함하며 앱 기본 다운로드 주소는 설정하지 않았다. HTTPS에서 이 파일의 최종 원문 주소를 앱에 설정하거나 파일 가져오기로 사용할 수 있다. `audit.json`의 원본 체크섬은 로컬에 보관한 다운로드 파일을 기준으로 하며 해당 원본 전체를 Git에 포함하지는 않는다.
